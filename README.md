# 陈璐简历

单页 A4 排版的求职简历，React + Vite + Tailwind CSS v4 构建，支持屏幕预览与打印 / 导出 PDF。

## 开发

```bash
pnpm install
pnpm dev      # 本地预览
pnpm build    # 构建到 dist/
pnpm lint     # 类型检查
```

## 字体：完全离线

简历使用的 4 款字体**全部打包在仓库里**，不加载任何 CDN（Google Fonts 在中国大陆访问不稳定）：

| 字体              | 用途                   | 体积    |
| ----------------- | ---------------------- | ------- |
| Noto Sans SC      | 中文正文               | ~128 KB |
| Noto Serif SC     | 姓名 / 标题 / 自我评价 | ~168 KB |
| Plus Jakarta Sans | 拉丁字母、数字         | ~18 KB  |
| JetBrains Mono    | 日期等等宽数字         | ~24 KB  |

字体文件位于 `src/assets/fonts/`，`@font-face` 声明见 `src/fonts.css`（自动生成，勿手改）。

子集是**按需生成**的：脚本先扫描 `src/**` 与 `index.html`，取出简历实际用到的全部字符（当前 508 个），再通过 Google Fonts CSS2 API 的 `text=` 参数配合 `wght@400..700` 可变字体轴，为每个字体族生成**只含这些字、单个文件覆盖全部字重**的 woff2，合计约 337 KB。

```bash
pnpm fonts:fetch   # 重新生成离线字体
```

> 注意：如果简历正文新增了此前从未出现过的字符（汉字、`×` 这类符号都算），需要重新运行 `pnpm fonts:fetch`，否则新字会回退到系统字体（不会乱码，只是字形不统一）。脚本结束时会校验「所有字符均有字形覆盖」。

字体均为 SIL Open Font License 1.1 授权，可随项目自由分发。

## 屏幕显示：任意尺寸自适应

简历纸张始终按 A4（210×297mm）排版，屏幕上的显示由 `src/components/A4Page.tsx` 负责：

- **屏幕宽于 A4**：纸张保持原始尺寸居中显示，左右留白。
- **屏幕窄于 A4**：整张纸按可用宽度**等比缩放**（`transform: scale()`），内部排版不重排，因此任何尺寸下都仍是同一页；缩放比例写在 CSS 变量 `--a4-scale` 上，纸张占位随之收缩，不会出现横向滚动条。
- **角落的悬浮按钮**：当两侧留白不足以容纳它时，纸张会自动下移一行，避免压住简历抬头。

缩放不影响打印：`@media print` 会取消缩放，始终按原始 A4 尺寸输出。

## 右上角二维码：扫码打开在线简历

纸张右上角放的是**在线简历地址的二维码**（内容 `https://chenlu.innenu.com/`），屏幕预览与打印 / 导出 PDF 都会输出，HR 打印后可直接扫码打开本页。

- 资源：`src/assets/qr-code.svg`（25×25 模块、ECC M、quiet zone 2 模块），随源码提交，不依赖任何 CDN；构建时体积小于 4 KB，会被 Vite 内联进 JS，不会额外发请求。
- 尺寸与位置：58px ≈ 15.3mm，位于**页眉（校徽那一行）的右上角**（打印时距上边约 9.5mm、右边 12mm），模块约 0.53mm，手机可稳定识别。
- 布局代价被压到最小：二维码用绝对定位挂在页眉右侧，**页眉高度与个人信息区宽度都不变**（电话 / 微信 / 邮箱一行不会被挤窄或换行）；校徽与两个资质标签改为居左相邻，为二维码让出右上角；「求职意向」标签整体下移 24px 并保持右对齐，避开二维码下沿。
- 因此整页内容比原来高约 6px；个人荣誉 / 实践经验 / 主要学生工作 / 自我评价四个区的行高已略微收紧（`leading-[1.4]` / `leading-[1.35]` / `leading-[1.45]`），打印仍是**单页**，底部留白约 9mm，与 10mm 页边距基本一致。

换网址时重新生成（与 `pnpm fonts:fetch` 一样只在需要时联网）：

```bash
pnpm dlx qrcode -t svg -q 2 -e M -o src/assets/qr-code.svg "https://新地址/"
```

## 打印 / 导出 PDF

点击页面右上角「打印 / 导出 PDF」，在浏览器打印对话框中选择 A4、边距「无」、并勾选「背景图形」，即可得到单页 PDF（字体已内嵌，任何设备打开效果一致）。

## 内容维护：重复获奖怎么标

奖项文案写在 `src/data/resumeData.ts` 的 `awards` 里，名字以「 ×N」结尾即表示该奖项获得过 N 次，页面会把 `×N` 渲染成**主题蓝加粗**，用来突出重复获奖：

```ts
items: ["国家奖学金（2026.10.10）", "优秀学生干部奖学金 ×2", "创新创业专项奖学金 ×2"],
```

> 新增文案如果用到此前没出现过的字符（例如 `×`），记得跑一次 `pnpm fonts:fetch`，让离线字体子集包含它。
