# 陈璐简历

单页 A4 排版的求职简历，React + Vite + Tailwind CSS v4 构建，支持屏幕预览与打印 / 导出 PDF。

## 开发

```bash
pnpm install
pnpm dev      # 本地预览
pnpm build    # 构建到 dist/
pnpm lint     # 类型检查
```

## 字体：完全离线

简历使用的 4 款字体**全部打包在仓库里**，不加载任何 CDN（Google Fonts 在中国大陆访问不稳定）：

| 字体              | 用途                   | 体积    |
| ----------------- | ---------------------- | ------- |
| Noto Sans SC      | 中文正文               | ~118 KB |
| Noto Serif SC     | 姓名 / 标题 / 自我评价 | ~154 KB |
| Plus Jakarta Sans | 拉丁字母、数字         | ~18 KB  |
| JetBrains Mono    | 日期等等宽数字         | ~24 KB  |

字体文件位于 `src/assets/fonts/`，`@font-face` 声明见 `src/fonts.css`（自动生成，勿手改）。

子集是**按需生成**的：脚本先扫描 `src/**` 与 `index.html`，取出简历实际用到的全部字符（约 470 个），再通过 Google Fonts CSS2 API 的 `text=` 参数配合 `wght@400..700` 可变字体轴，为每个字体族生成**只含这些字、单个文件覆盖全部字重**的 woff2，合计约 315 KB。

```bash
pnpm fonts:fetch   # 重新生成离线字体
```

> 注意：如果简历正文新增了此前从未出现过的汉字，需要重新运行 `pnpm fonts:fetch`，否则新字会回退到系统字体（不会乱码，只是字形不统一）。

字体均为 SIL Open Font License 1.1 授权，可随项目自由分发。

## 屏幕显示：任意尺寸自适应

简历纸张始终按 A4（210×297mm）排版，屏幕上的显示由 `src/components/A4Page.tsx` 负责：

- **屏幕宽于 A4**：纸张保持原始尺寸居中显示，左右留白。
- **屏幕窄于 A4**：整张纸按可用宽度**等比缩放**（`transform: scale()`），内部排版不重排，因此任何尺寸下都仍是同一页；缩放比例写在 CSS 变量 `--a4-scale` 上，纸张占位随之收缩，不会出现横向滚动条。
- **角落的悬浮按钮**：当两侧留白不足以容纳它时，纸张会自动下移一行，避免压住简历抬头。

缩放不影响打印：`@media print` 会取消缩放，始终按原始 A4 尺寸输出。

## 打印 / 导出 PDF

点击页面右上角「打印 / 导出 PDF」，在浏览器打印对话框中选择 A4、边距「无」、并勾选「背景图形」，即可得到单页 PDF（字体已内嵌，任何设备打开效果一致）。
