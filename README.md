# 陈璐 · 在线简历

一张 A4 纸刚好放下的求职简历，打开网页就能看，也能一键打印或导出为 PDF。线上地址：<https://chenlu.innenu.com/>

## 这是什么

陈璐的个人简历主页。整份简历按 **A4 纸张（210 × 297 mm）** 排版，屏幕预览与打印输出是同一份内容，不会因为换设备就「排版跑掉」。

## 怎么看

- **手机**：直接打开 <https://chenlu.innenu.com/>，整张纸会按屏幕宽度等比缩放，上下滑动即可。
- **电脑**：纸张居中显示，宽屏时保持原始 A4 尺寸。
- **纸质 / PDF**：点右上角「打印 / 导出 PDF」，在打印对话框里选 A4、边距「无」、勾选「背景图形」，得到的就是单页 PDF。
- **纸面扫码**：简历右上角印有二维码，HR 打印后可以直接扫码回到本页。
